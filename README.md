# Tambang Safety System

Sistem web open source gratis untuk monitoring keselamatan kerja di area tambang.

## Fitur

- Dashboard keselamatan kerja
- Form pelaporan insiden / near miss
- Monitoring PPE karyawan
- Data pelatihan dan sertifikasi
- Daftar karyawan dan status kesiapan kerja
- Data tersimpan di browser menggunakan localStorage

## Teknologi

- HTML
- CSS
- JavaScript
- Tanpa framework tambahan
- Gratis dan mudah dijalankan

## Cara Menjalankan

1. Unduh atau clone repo ini.
2. Buka file `index.html` di browser.
3. Aplikasi siap digunakan.

Untuk browser modern seperti Chrome, Edge, Firefox, atau Safari.

## Struktur File

- `index.html` — antarmuka utama
- `style.css` — desain dan layout
- `script.js` — logika dashboard dan form

## Catatan

Ini adalah versi MVP yang dapat dikembangkan lebih lanjut menjadi:
- login admin
- database PostgreSQL
- integrasi API
- dashboard ekspor PDF
- notifikasi WhatsApp / email
- tracking lokasi pekerja
